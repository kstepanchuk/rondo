## Установка

**Homebrew**

```bash
brew install --cask kstepanchuk/rondo/rondo
```

**DMG**: скачайте `Rondo-x.y.z.dmg` из [Releases](https://github.com/kstepanchuk/rondo/releases/latest) и перетащите Rondo в «Программы».

> [!NOTE]
> Приложение не нотаризовано. Если после установки из DMG macOS не даёт его открыть, перетащите **«Разрешить запуск»** из DMG в окно Терминала и нажмите Enter: скрипт снимет карантин только с Rondo.app и откроет его. Или: *Системные настройки → Конфиденциальность и безопасность → Всё равно открыть*. При установке через brew это не нужно.

**Дополнительные движки** (по желанию):

```bash
brew install ffmpeg pandoc sevenzip
```

Конвертация DOCX, XLSX и PPTX в PDF использует Microsoft Office или Keynote, если они доступны. Если их нет, установите LibreOffice с открытым исходным кодом: `brew install --cask libreoffice`. Rondo запускает его в фоновом режиме, не открывая офисное приложение. Если установлены оба, движок выбирается в Настройках → Инструменты → «Движок для документов».

**Обновления.** Rondo раз в день проверяет GitHub Releases, перед установкой сверяет SHA-256 и подпись и сам перезапускается. Проверить вручную можно через меню «Проверить обновления…».

## Как пользоваться

| | Клавиша | Режим |
|---|---|---|
| 🔄 | <kbd>⇧ Shift</kbd> | Конвертация |
| 🛠 | <kbd>⌃ Control</kbd> | Инструменты |
| ⚡️ | <kbd>⌥ Option</kbd> | Действия |

1. Начните тянуть файл (или несколько) из Finder, браузера, Почты или Фото.
2. Зажмите модификатор: у курсора раскроется колесо. Модификатор можно менять на ходу или **прокручивать** колёсиком над колесом.
3. Отпустите файл над сектором. Центр колеса отменяет действие. Задержитесь на **«Ещё ›»**, чтобы открыть второе кольцо.

**Без мыши**: выделите файлы в Finder и нажмите <kbd>⌃⌥Space</kbd>. <kbd>Tab</kbd> меняет режим, стрелки и <kbd>Enter</kbd> выбирают, <kbd>Esc</kbd> закрывает меню.
**Через контекстное меню**: правый клик → Службы → **Rondo…**
**«Быстрые команды» и Spotlight**: действия *Convert Files with Rondo* (любой формат), *Convert to JPEG*, *Compress* и *Convert to PDF* работают в «Командах», автоматизациях папок и Spotlight без колеса.
**Папки-наблюдатели**: в настройках выберите папку и действие, и новые файлы в ней будут обрабатываться сами, результат — в подпапке «Готово».

**Командная строка**: тот же движок в Терминале.

```bash
rondo convert --to jpg *.heic        # результат рядом с каждым исходником (или --out ПАПКА)
rondo list photo.CR3                 # во что можно превратить файл
rondo run fit-8 video.mp4            # любая операция по id, например «до 8 МБ»
rondo info photo.CR3                 # камера, объектив, экспозиция, кодеки, страницы…
```

<details open>
<summary><b>🛠 Инструменты</b></summary>

- **Изображения**: **кроп** (1:1, 4:5, 9:16, 16:9… в редакторе) и квадрат, убрать фон, **ужать до 1 / 5 / 8 / 25 МБ**, уменьшить, повернуть, отразить, удалить EXIF и GPS, распознать текст (OCR), прочитать QR-код, «для веба», палитра цветов.
- **RAW**: кроп, ужать до N МБ, быстрое превью (встроенный JPEG камеры), данные съёмки в буфер (камера, объектив, выдержка, диафрагма, ISO), «для веба», палитра.
- **PDF**: разложить в PNG, OCR, QR, разбить по страницам, сжать, **повернуть, номера страниц, оставить / удалить страницы, водяной знак**.
- **Презентации** ³: разложить в PNG. Слайды 16:9 получаются ровно **1920×1080**.
- **Видео** ¹: **ужать до 8 / 25 МБ** (Discord, почта), **обрезать по времени и кадрировать** (16:9, 9:16, 1:1, 4:5) в редакторе, как в QuickTime, сжать, убрать звук, первый кадр, извлечь субтитры, вертикаль **9:16** для Reels и Shorts, **720p, поворот, ускорение ×2**, расшифровать речь.
- **Аудио** ¹: **теги и обложка**, **обрезать по времени**, моно, выровнять громкость, убрать тишину, расшифровать речь.
- **Текст**: **в UTF-8** из Windows-1251, KOI8-R, DOS-866, UTF-16 (TXT, CSV, SRT, MD, JSON…).
- **Несколько файлов**: объединить в PDF, коллаж, **склеить видео или аудио** в один файл.
- После сжатия видна экономия: `1,2 МБ → 340 КБ (−72 %)`.

</details>

<details open>
<summary><b>⚡️ Действия</b></summary>

ZIP, AirDrop, **«На телефон»** (QR-код, локальный Wi-Fi, 5–30 мин), **своя иконка** для папки или файла, **«Поделиться»** в любое приложение, **«Полочка»** (плавающее окошко, из которого файл можно перетащить дальше), **«Переместить в…»**, копировать путь, показать в Finder, **открыть в Терминале**, **метаданные** (камера, GPS, кодеки, сведения PDF), SHA-256, дубликат, 7Z ⁴, распаковать (ZIP, 7Z, RAR, TAR…), ZIP нескольких файлов.

**🎛 Resolume Arena**: перетащите папку со слайдами с ⌥ на «В Arena как деку». В Arena появится новая дека с именем папки, картинки и видео встанут в клипы первого слоя по порядку (1, 2 … 10). Нужен включённый веб-сервер Arena (Preferences → Webserver, порт 8080 меняется в расширенных настройках).

**Свои действия**: создайте в «Быстрых командах» папку **Rondo**, и её команды появятся в этом колесе.

</details>

А ещё: **отмена** и перетаскивание результата прямо из уведомления, подсказки в центре колеса, карточка файла под колесом, колесо запоминает порядок использования, приветственный тур.

## Настройки

- Тема: как в системе, тёмная (красно-чёрная) или светлая (бело-голубая).
- Язык: как в системе, русский или английский.
- Куда сохранять: **рядом с исходным файлом** (по умолчанию) или в `~/Downloads/Rondo`.
- Запуск при входе в систему, показ результата в Finder, автообновления.
- **Расширенные** (по желанию): качество JPG/HEIC и видео, размер «для веба», переназначение клавиш режимов (⇧ ⌃ ⌥ ⌘), порядок и скрытие секторов колеса для каждого типа файлов.
- Статус движков и команды для их установки в один клик.

## Приватность и безопасность

- Файлы не покидают Mac, телеметрии нет. В сеть приложение выходит только для проверки обновлений на GitHub.
- Исходные файлы не перезаписываются: при совпадении имён добавляется ` (2)`, ` (3)`…
- ffmpeg работает только с протоколом `file`, pandoc запускается с `--sandbox`. Архивы не распаковываются за пределы папки.
- Не нужен «Универсальный доступ»: модификаторы считываются без перехвата клавиатуры.
- Hardened runtime. Из прав запрашивается только управление Finder и Office.

## Сборка

```bash
./scripts/build.sh 0.2.0     # dist/Rondo.app, Rondo-0.2.0.dmg и .sha256
./scripts/ci-test.sh         # сквозные тесты, те же, что запускает CI
```

Релиз: `git tag vX.Y.Z && git push --tags`, после чего GitHub Actions соберёт и опубликует DMG.

Помощь приветствуется, подробности в [CONTRIBUTING.md](CONTRIBUTING.md).
